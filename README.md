# Sarveksha ERP

Procurement and Vendor Management ERP system for Sarveksha Group, built on Frappe Framework.

---

## Version: `1.1.2`

### Versioning Scheme (`X.Y.Z`)
* **1st digit (`X`)**: Initial deployed release (currently initial deployment `1`).
* **2nd digit (`Y`)**: Number of times major changes performed.
* **3rd digit (`Z`)**: Number of times minor changes done.

---

## Overview

Sarveksha ERP provides procurement workflows, purchase order lifecycle management, dynamic multi-entity corporate letterheads, and automated tax governance across Sarveksha Group entities.

### Key Capabilities
- **Vendor Purchase Orders**: Multi-entity PO generator with approval verification workflows, dual-currency support (INR & USD), and dynamic shipping mode selection (Waterway, Flightway, Roadway, Courier).
- **Direct GST Computation**: Auto-determines IGST (inter-state) vs. CGST + SGST (intra-state) from editable GST % entries.
- **Corporate Letterheads**: Lossless 300 DPI corporate letterheads for India, Cameroon (PLC, Mining, Baani), Botswana, Guinea, and Sierra Leone entities.
- **Formal Print Engine**: Fixed-layout formal purchase order formats with terms and signatures.
