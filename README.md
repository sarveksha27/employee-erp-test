# Sarveksha ERP

A clean, modern Procurement ERP application designed for the Sarveksha Group. This is a custom Frappe application designed for Frappe Framework v16 that integrates seamlessly into ERPNext.

## Core Features
1. Equipment Enquiry & Purchase Lifecycle Management
2. Multi-Company & Multi-Currency Support
3. Container Shipping & PI Container Tracking
4. Payments & Invoices Stage Tracking
5. Comprehensive Financial and Procurement Reports
6. Unified Management Dashboard

## Installation
To install this application on your Frappe bench, run:
```bash
bench get-app sarveksha_erp
bench install-app sarveksha_erp
```
