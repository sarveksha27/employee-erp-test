# Sarveksha Vendor

Vendor Payment Tracking module for a multi-company organization built on top of **Frappe Framework v16** and **ERPNext v16**.

## Features

- **Multi-Company Support**: Native support for six independent companies with distinct currencies (INR, AED, GNF, XAF, BWP, SLE).
- **Tax Configurations**: Custom automatic tax calculations tailored to regions (GST 18% & TDS for India, VAT for UAE, Guinea, Cameroon, Botswana, Sierra Leone).
- **Custom DocTypes**: Vendor Contracts, Vendor Payment Requests, Shipment tracking, Equipment tracking, Customs Clearance, Payment Batches, and Intercompany Transfers.
- **Workflow Automation**: Purchase Order → Vendor Invoice → Finance Review → Approval → Payment Request → Payment Entry.
- **Dynamic Dashboard**: Vendor Payment Tracking Workspace with KPI cards and analytical reports.
- **Production Bootstrap Data Seeding Tool**: Automated CLI command to set up 20+ vendors, 40+ POs, invoices, shipments, customs clearances, and payment requests.

## Installation

To fetch and install the app to your Bench instance:

```bash
bench get-app https://github.com/sarveksha/sarveksha_vendor.git
bench --site development.localhost install-app sarveksha_vendor
bench migrate
```
